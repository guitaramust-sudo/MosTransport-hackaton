# Conductor — Idle / Walk

Готовый персонаж проводницы на основе исходного `901887286b53f812d4727b9b2c11433e.glb`. Внешность, одежда, UV и исходный материал сохранены. Добавлены простой игровой скелет, skinning и два анимационных клипа.

| Параметр | Значение |
|---|---|
| Character | Conductor |
| Actions | `Idle`, `Walk` |
| Walk type | In-place loop |
| FPS | 30 |
| Walk frames в Blender | 1–31, кадр 31 совпадает с кадром 1 |
| Walk playback | 1–30, затем повтор |
| Walk duration в GLB | 1,0 с |
| Idle frames в Blender | 1–61 |
| Blender forward / up | −Y / +Z |
| GLB forward / up | +Z / +Y |
| Root motion | No |
| Loopable | Yes |
| Recommended playback speed | 0,75–1,25× |

## Файлы

- `conductor_animated.blend` — редактируемая сцена; `CharacterRoot → Armature → CharacterMesh`, отдельная коллекция предпросмотра.
- `conductor_animated.glb` — персонаж, skin и только `Idle`/`Walk`, без камер, света, пола и IK-объектов.
- `animate_conductor.py` — повторяемая сборка из указанного исходного GLB.
- `verify_conductor.py` и `verification.json` — проверка сохранённой сцены и чистого импорта GLB.
- `previews/walk_side.mp4`, `walk_front.mp4`, `walk_gameplay.mp4` — 30 кадров одного цикла с трёх камер.

## Использование в React Native / Three.js

Анимируйте `Walk` по кругу, когда персонаж движется, и `Idle`, когда он остановлен. Для перехода используйте crossfade примерно **0,15–0,25 с**. Перемещайте и разворачивайте **весь `CharacterRoot`** игровым кодом. Локальная ось взгляда после импорта GLB — **+Z**; направление зависит от вашего movement vector. В анимации нет движения корня вперёд или в стороны.

Скорость перемещения задаётся в приложении. Скорость клипа можно менять в диапазоне 0,75–1,25× в зависимости от movement speed. Для плавной опоры согласуйте игровую скорость с длиной шага. Файл подготовлен в исходном масштабе персонажа, высота около **1,19 м**.

## Проверка и ограничение

После экспорта GLB повторно импортирован в пустую сцену Blender: присутствуют материал, skin, 20 костей, `Idle` и `Walk`; измеренный разрыв между началом и концом `Walk` — **0 м**, `CharacterRoot` неподвижен. В первых кадрах фазы опоры локальная стопа фиксирована; во время остальной опоры стопа проходит назад относительно неподвижного корня, чтобы её движение компенсировалось перемещением персонажа в игре.

Исходный меш содержит **50 000 треугольников** и три текстурных изображения. Геометрия и текстуры намеренно не упрощались; для массового использования персонажей на мобильных устройствах потребуется отдельный LOD.

Повторная сборка в Blender 5.x:

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --python animate_conductor.py
```

Чтобы одновременно пересоздать MP4, добавьте перед командой `CONDUCTOR_RENDER_VIDEOS=1`.
