# Проводник ВСМ – мобильный клиент

Мобильный тренажёр для подготовки проводников высокоскоростных магистралей. Приложение построено на Expo, React Native и TypeScript.

## Возможности MVP

- главная панель с уровнем, XP и недельным прогрессом;
- каталог учебных сценариев;
- интерактивная смена с параллельными событиями;
- независимые метрики безопасности и лояльности;
- критические события с таймером;
- выбор действий и изменение состояния сессии;
- итоговый разбор каждого решения;
- профиль профессиональных компетенций.
- игровая 3D-сцена вагона с анимированной проводницей;
- переключение `Idle`/`Walk`, перемещение между событиями и выбор приоритета;
- параллельные задачи и содержательный таймер с игровыми последствиями.

Демонстрационный сценарий работает локально. Backend не требуется для запуска интерфейса и в рамках этой реализации не изменялся.

## Запуск

Сначала запустите backend: `cd backend && docker compose up --build`.

```bash
cd frontend
npm install
EXPO_PUBLIC_API_URL=http://localhost:8088 npm run web
```

Для Android эмулятора адрес по умолчанию – `http://10.0.2.2:8088`. Для физического устройства задайте `EXPO_PUBLIC_API_URL=http://<адрес-компьютера-в-локальной-сети>:8088` перед `npm start`. Backend должен быть доступен устройству.

Создайте аккаунт на экране входа, начните смену, выберите ситуацию, отправьте реплику и при необходимости вызовите адресата. Итоговый разбор и XP приходят с сервера. Токены пока хранятся только в памяти приложения: после перезапуска нужно войти снова.

Для iOS-сборки без Expo Go требуется macOS. Проверка типов:

```bash
npm run typecheck
```

## Структура

```text
src/
├── app/          # Redux store и состояние сессии
├── components/   # переиспользуемые компоненты
├── data/         # демонстрационные сценарии
├── helpers/      # тема, токены и функции
├── pages/        # экраны приложения
└── types/        # типы сущностей

assets/
├── models/       # вагон: исходный .blend и runtime .glb
└── characters/   # runtime-модели персонажей

tools/blender/    # исходники и скрипты сборки 3D-ассетов
docs/             # проверки и превью анимаций
```

## Игровой цикл

Откройте сценарий «Сложная смена», затем нажмите на карточку события в 3D-сцене. Проводница дойдёт до нужной зоны с анимацией `Walk`, остановится в `Idle`, после чего появятся доступные действия. События существуют параллельно, поэтому игрок сам выбирает приоритет. Истечение критического таймера автоматически изменяет Safety и Loyalty и попадает в итоговый разбор.

React Query подключён в корне приложения и готов для интеграции с REST API. Redux хранит навигацию демо-версии и состояние текущей игровой сессии, поэтому данные не передаются через цепочки props.
