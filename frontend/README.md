# Проводник ВСМ — мобильный клиент

Expo/React Native клиент тренажёра. Вход, смена, диалог, эскалация, скоринг и профиль работают через backend API. Шкалы обновляются после закрытия ситуации.

## Запуск

Сначала запустите backend: `cd backend && docker compose up --build`.

```bash
cd frontend
npm install
EXPO_PUBLIC_API_URL=http://localhost:8088 npm run web
```

Для Expo Go на физическом Android приложение автоматически берёт IP компьютера из адреса Expo и обращается к backend на порту `8088`. Телефон и компьютер должны находиться в одной сети, а порт `8088` должен быть разрешён брандмауэром.

Если автоопределение не подходит, адрес можно задать явно перед запуском:

```powershell
$env:EXPO_PUBLIC_API_URL="http://192.168.1.10:8088"
npm start
```

Для Android-эмулятора резервный адрес — `http://10.0.2.2:8088`, для web — `http://localhost:8088`.

Создайте аккаунт на экране входа, начните смену, выберите ситуацию, отправьте реплику и при необходимости вызовите адресата. Итоговый разбор и XP приходят с сервера. Токены пока хранятся только в памяти приложения: после перезапуска нужно войти снова.

Проверка типов: `npm run typecheck`.

## Запуск всего проекта через Docker

Из корня репозитория выполните:

```powershell
docker compose up --build
```

После сборки доступны:

- приложение: `http://localhost:8081`;
- backend API: `http://localhost:8088`;
- PostgreSQL: `localhost:5432`.

Остановить контейнеры: `docker compose down`. Данные PostgreSQL сохраняются в Docker volume `pgdata`.
